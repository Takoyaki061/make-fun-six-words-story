Entry for the [Six Words, One Story](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410) bounty on make.fun.

`main.py` writes one complete story in exactly six words to `/output/entry.txt`:

> I wrote it. He died waiting.

A letter written but never sent; the man it was meant for died waiting for it. Beginning, turn, and aftermath in six words — the letter's contents left for the reader to fill in.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
